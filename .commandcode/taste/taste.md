# Taste

- Wants work history / findings persisted to a local file in the workspace (e.g. a WORKLOG.md) rather than living only in chat, so context survives across sessions, and asks for the session itself to be saved/exported to disk. This extends to multi-agent setups: when another agent works in the same repo, wants ONE unified memory both agents read and write so each knows what the other is doing, rather than per-agent notes. Confidence: 0.8
- Prefers the full scope of prerequisites/requirements enumerated before committing to a build or platform choice ("before we dive in, list the complete things needed"), rather than starting implementation straight away. Confidence: 0.5
- Prefers building features custom in-house rather than adopting off-the-shelf platforms (rejected WHMCS: "we don't need it since we are going to code everything ourselves"). Confidence: 0.65
- Prefers crypto payment rails (e.g. Zeno Bank) over card processors like Stripe; don't assume Stripe/card integration in plans. Confidence: 0.55
